# Контент-стратегия AiProhar

Этот раздел хранит исследования и рабочую систему органического контента AiProhar для Telegram, Instagram, VK, YouTube, TikTok, Дзен и других актуальных площадок.

## Статус

**Активен первый пилотный цикл.** Владелец разрешил подготовить текстовый контент-пакет по демонстрационному проекту NERÉIDE для Instagram, Telegram и VK.

Разрешение относится только к производству материалов. Не назначать даты, не публиковать контент и не запускать автоматический постинг без отдельной прямой команды владельца.

## Обязательное правило для агента

При любом запросе о продюсировании, социальных сетях, органическом трафике, контент-стратегии, конкурентах, рубриках, постах, видео, Stories, Reels, Shorts, VK Клипах, лид-магнитах или переупаковке контента:

1. Сначала прочитать этот файл.
2. Затем открыть документ, соответствующий задаче:
   - анализ рынка и конкурентов — [competitors.md](competitors.md);
   - позиционирование, рубрики, производство и метрики — [aiprohar-playbook.md](aiprohar-playbook.md);
   - выбор стартовой темы — [idea-backlog.md](idea-backlog.md).
3. Проверить актуальность изменчивых фактов и правил площадок по первоисточникам.
4. Учитывать текущий статус: производство разрешено только для утверждённого пилота, а публикация требует отдельной прямой команды владельца.
5. Не копировать голос и формулировки конкурентов. Использовать их материалы только как сигнал спроса и источник механик.

## Главная стратегическая территория

> AiProhar с телефона превращает реальные задачи в работающие сайты, приложения и AI-системы и показывает весь путь: от сообщения клиента до кода, проверки и деплоя.

Это не обещание немедленно вести все социальные сети. Это ориентир, который помогает не потерять отличительную идею, когда работа над контентом возобновится.

## Как вести пилотный цикл

Для утверждённого пилота:

1. Использовать цель, аудиторию, доказательства и CTA из [nereide-pilot.md](nereide-pilot.md).
2. Создать один основной материал и нативные версии для трёх площадок, а не одинаковый текст.
3. Проверить все фактические утверждения по артефактам проекта.
4. Перед публикацией показать владельцу финальные тексты и визуалы.
5. После отдельного разрешения на публикацию снять первичные показатели через 48–96 часов и сохранить выводы.

Не начинать с месячного календаря, ежедневных обязательств или запуска всех площадок одновременно.
